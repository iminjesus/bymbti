# 🧬 bymbti

**아무 질문이나 던지면, MBTI 16유형별 "예상 정답"과 그 사람에게 딱 맞는 역할을 배정해 주는 웹앱.**

> 예) `지구 온난화의 영향과 해결 방안에 대해 조사하고 발표하시오`
> → 누가 팀장을 하고, 누가 자료를 조사하고, 누가 발표해야 하는지 MBTI 기준으로 자동 배정

조별과제 지뢰 제거용입니다. 밈은 덤. 🙂

---

## 뭘 해주나요

| 기능 | 설명 |
|---|---|
| 🧭 **과제 분석** | 입력한 질문의 유형(발표형/조사형/토론형/기획형/제작형…), 핵심 주제, 답변에 들어가야 할 축, 추천 결과물을 뽑아냅니다. |
| 🗓️ **진행 로드맵** | 주제 쪼개기 → 자료 수집 → 아이디어 수렴 → 제작 → 리허설 → 제출까지, 단계마다 어떤 역할이 주도할지 붙여줍니다. |
| 👥 **우리 조 역할 배정** | 조원 이름 + MBTI를 넣으면 **역할이 겹치지 않게** 최적 배치합니다. 각자 "첫 미션"까지 나옵니다. |
| 🔮 **조 케미 진단** | 전원 P 조 / 전원 T 조 같은 지뢰 조합을 미리 경고합니다. |
| 🧬 **16유형 카드** | 같은 질문에 대해 유형별로 **어떻게 다르게 답하는지**, 회의에서 할 법한 한마디, 강점, 역량 프로필, 잘 맞는 짝까지. |
| ✨ **AI 모드 (선택)** | Claude API 키를 넣으면 유형별 답변을 Claude가 새로 써 줍니다. **키 없이도 앱 전체가 동작합니다.** |

## 어떻게 배정하나요 (하드코딩된 정답표 없음)

역할은 표를 보고 고르는 게 아니라 **매번 계산**합니다.

```
1. 16유형의 인지기능 스택(주기능 → 부기능 → 3차 → 열등)과 4개 지표(E/I·S/N·T/F·J/P)에서
   12개 역량 점수를 계산한다.
     예) Te → 통솔력·기획·실행,  Si → 꼼꼼함·자료조사,  Ne → 아이디어,  Fe → 팀 조율·전달력
     스택 위치별 가중치: 주 1.0 / 부 0.75 / 3차 0.40 / 열등 0.15

2. 입력된 질문을 읽고 이 과제에 어떤 역량이 더 필요한지 가중치를 매긴다.
     "발표"가 들어가면 전달력·시각화 ↑,  "토론"이면 설득력·논리 ↑ …

3. 역할별 요구 역량(need)과 유형의 역량 점수를 내적해 적합도를 낸다.
     적합도 × 과제 우선순위 = 최종 점수

4. 조 모드에서는 전역 그리디 + 쌍 교환 최적화로 팀 전체 점수가 최대가 되게 배정한다.
   (3명 이상이면 팀장은 반드시 채워진다)
```

역량 12종: 통솔력 · 기획일정 · 자료조사 · 논리분석 · 아이디어 · 꼼꼼함 · 팀조율 · 실행력 · 전달력 · 시각화 · 문서화 · 설득력
역할 12종: 팀장 · 일정관리 · 자료조사 · 아이디어발산 · 논리검증 · 발표 · 디자인 · 보고서 · 팀조율 · 실행섭외 · 서기 · 리스크점검(악마의 변호인)

"예상 정답"도 같은 원리입니다. 주기능이 답변의 **접근 방식**을, 부기능이 **보완 방식**을, 열등기능이 **함정**을 결정합니다.

## 실행 방법

정적 사이트라 빌드가 필요 없습니다.

```bash

open index.html

```

**GitHub Pages 배포:** Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 지정하면 끝입니다.

## ✨ AI 모드 (선택 사항)

앱 하단 **⚙️ 고급 설정**에서 Anthropic API 키를 넣으면 유형별 답변을 Claude(`claude-sonnet-5`)가 다시 써 줍니다.

- 키는 **브라우저 localStorage에만** 저장되고, Anthropic API 외 어디로도 전송되지 않습니다 (별도 백엔드 없음).
- 공용 PC에서는 사용 후 **삭제** 버튼을 꼭 누르세요.
- 사용량만큼 요금이 청구됩니다.
- **키가 없어도 앱의 모든 기능은 규칙 기반으로 완전히 동작합니다.**

## 파일 구조

```
index.html
assets/
  css/style.css
  js/
    mbti-data.js   16유형 원자료 + 인지기능 → 역량 점수 계산 + 한국어 조사 처리
    roles.js       역할 12종 + 요구 역량
    analyzer.js    질문 분석 (과제 유형 / 주제 / 답변 축 / 키워드)
    engine.js      역할 배정 알고리즘 + 조 케미 진단
    answers.js     MBTI별 예상 정답 생성
    llm.js         (선택) Claude API 호출
    app.js         UI
```
