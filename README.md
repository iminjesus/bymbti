# 🧬 byMBTI — 그래서 넌 뭐 할 건데?

**네가 안 정하면 16명이 정해준다.**
아무 질문이나 던지면 MBTI 16유형이 각자 답하고, 그 상황에서 각자 맡을 자리까지 나눠주는 설치형 웹앱.

> `오늘 짜장면 먹을까 짬뽕 먹을까`
> → 🏆 짜장면 8표 / 짬뽕 6표 / "둘 다 안 돼?" 2표 (ENFP·ENTP)
> → ENTJ는 최종 결정권자, ENFP는 제3의 메뉴 투척, ISFJ는 "아무거나" 담당

> `지구 온난화의 영향과 해결 방안에 대해 조사하고 발표하시오`
> → 누가 팀장이고 누가 자료 조사하고 누가 발표하는지 + 진행 로드맵

정답률은 책임 안 집니다. 그 유형답고 웃기면 그게 정답입니다. 🙃

## 뭘 해주나요

| 기능 | 설명 |
|---|---|
| 🧭 **상황 판별** | 질문이 과제인지, 메뉴 고민인지, 날씨인지, 연애 상담인지, 지름신인지, 그냥 넋두리인지 먼저 가릅니다. 상황이 바뀌면 포지션과 답변이 통째로 바뀝니다. |
| 🗳️ **16유형 투표** | "A 할까 B 할까" 형태면 16유형이 각자 하나를 고르고, 득표수를 막대로 보여줍니다. Ne 주기능(ENFP·ENTP)은 항상 "둘 다 안 돼?" 쪽으로 갑니다. |
| 🎯 **16유형의 답** | 어떤 질문이든 유형마다 하나씩 답을 냅니다. "오늘 뭐 먹지"에 ESTJ는 국밥("빠르고 실패가 없어"), INTJ는 샐러드("먹고 나서 후회 안 하는 쪽으로"), INTP는 편의점 도시락("가격 대비 효율이 압도적이야"). 선택지를 안 줘도, 말이 안 되는 질문이어도 답은 나옵니다. 틀릴 수 있지만 이유는 전부 붙습니다. |
| 🔢 **번호 배정표** | "N개 중 하나 골라" 꼴이면 16유형이 **실제 번호를 하나씩 찍습니다.** 1~16이면 정확히 1번부터 16번까지 한 명씩 배정됩니다 — ESTJ 1번("순서대로 하는 게 맞지"), INTJ 16번("앞사람들이 나 대신 데이터를 만들어준다"). 범위가 1~45든 1~10이든 같은 축을 비례로 투영합니다. |
| ⚔️ **T vs F 섹션** | MBTI 최대 떡밥을 따로 뗐습니다. 상황마다 T진영/F진영이 뭐라고 하는지, "T가 한 말 → F가 들은 말" 번역, 그리고 **T발지수**(이 상황에서 팩트를 꺼내면 얼마나 위험한지)를 보여줍니다. |
| 💬 **유형별 실제 대답** | 성격 묘사가 아니라 **질문에 대한 답**이 나옵니다. 주기능이 접근을, 부기능이 끝맺음을 결정해서 16개가 전부 다릅니다. |
| 👥 **포지션 배정** | 이름 + MBTI를 넣으면 **겹치지 않게** 최적 배치합니다. 각자 "첫 미션"까지 나옵니다. |
| 🔮 **케미 진단** | 전원 P / 전원 T 같은 지뢰 조합을 미리 경고합니다. |
| 🗓️ **진행 로드맵** | 과제로 판별됐을 때만 나옵니다. 단계마다 어떤 역할이 주도할지 붙여줍니다. |
| ✨ **AI 모드 (선택)** | Claude API 키를 넣으면 유형별 답변을 Claude가 새로 써 줍니다. **키 없이도 앱 전체가 동작합니다.** |

## 어떻게 배정하나요 (하드코딩된 정답표 없음)

포지션은 표를 보고 고르는 게 아니라 **매번 계산**합니다.

```
0. 질문을 읽고 어떤 상황인지 판별한다. 상황이 정해지면 그 상황의 포지션 8종이 후보가 된다.
   "A 할까 B 할까" 꼴이면 선택지 두 개를 뽑아낸다.

1. 16유형의 인지기능 스택(주기능 → 부기능 → 3차 → 열등)과 4개 지표(E/I·S/N·T/F·J/P)에서
   12개 역량 점수를 계산한다.
     예) Te → 통솔력·기획·실행,  Si → 꼼꼼함·자료조사,  Ne → 아이디어,  Fe → 팀 조율·전달력
     스택 위치별 가중치: 주 1.0 / 부 0.75 / 3차 0.40 / 열등 0.15

2. 그 상황에 어떤 역량이 더 필요한지 가중치를 매긴다.
     "발표"가 들어가면 전달력·시각화 ↑,  양자택일이면 통솔력·논리 ↑ …

3. 포지션별 요구 역량(need)과 유형의 역량 점수를 내적해 적합도를 낸다.
     적합도 × 상황 우선순위 = 최종 점수

4. 여러 명 모드에서는 전역 그리디 + 쌍 교환 최적화로 전체 점수가 최대가 되게 배정한다.
   (3명 이상이면 그 상황의 중심 포지션은 반드시 채워진다)
```

역량 12종: 통솔력 · 기획일정 · 자료조사 · 논리분석 · 아이디어 · 꼼꼼함 · 팀조율 · 실행력 · 전달력 · 시각화 · 문서화 · 설득력

**답변 생성**도 같은 원리입니다.

- **주기능**이 접근 방식과 답의 방향을 정한다 (Si면 "지난번엔 어땠지", Se면 "지금 당기는 거")
- **부기능**이 끝맺음을 정한다 → 그래서 ISTJ와 ISFJ는 주기능이 같아도 답이 다르다
- **열등기능**이 함정을 정한다
- 양자택일이면 유형 코드 + 선택지 해시로 **결정적으로** 한쪽을 고른다. 같은 질문엔 항상 같은 표가 나온다.
  단, Ne 주기능(ENFP·ENTP)은 예외 없이 "둘 다 / 제3의 길"로 샌다.

## 앱으로 설치하기 (PWA)

설치형 웹앱입니다. 홈 화면에 추가하면 **주소창 없이 전체화면**으로 뜨고, **오프라인에서도 그대로 동작**합니다. 스토어를 거치지 않습니다.

먼저 GitHub Pages 주소로 접속하세요 → `https://iminjesus.github.io/bymbti/`

| 기기 | 설치 방법 |
|---|---|
| **Android (Chrome)** | 우측 상단 `⋮` → **앱 설치** (또는 하단에 뜨는 "홈 화면에 추가" 배너) |
| **iPhone / iPad (Safari)** | 하단 **공유 버튼** `⬆️` → **홈 화면에 추가** |
| **Windows / macOS (Chrome·Edge)** | 주소창 오른쪽 **설치 아이콘** `⊕` → **설치** |

> ⚠️ 설치 기능은 `https://` 또는 `localhost` 에서만 동작합니다. `index.html`을 파일로 직접 열면(`file://`) 앱 설치와 오프라인 캐시는 켜지지 않습니다. 앱 기능은 안 되지만 나머지 기능은 전부 정상입니다.

## 그냥 실행하기

정적 사이트라 빌드가 필요 없습니다.

```powershell
# Windows (PowerShell)
git clone -b main https://github.com/iminjesus/bymbti
cd bymbti
start index.html
```

```bash
# macOS / Linux
git clone -b main https://github.com/iminjesus/bymbti
cd bymbti
open index.html      # Linux 는 xdg-open index.html
```

설치·오프라인까지 확인하려면 로컬 서버로 띄우세요:

```bash
python -m http.server 8000   # → http://localhost:8000
```

**GitHub Pages 배포:** Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 지정하면 끝입니다.

## ✨ AI 모드 (선택 사항)

앱 하단 **⚙️ 고급 설정**에서 Anthropic API 키를 넣으면 유형별 답변을 Claude(`claude-sonnet-5`)가 다시 써 줍니다.

- 키는 **브라우저 localStorage에만** 저장되고, Anthropic API 외 어디로도 전송되지 않습니다 (별도 백엔드 없음).
- 공용 PC에서는 사용 후 **삭제** 버튼을 꼭 누르세요.
- 사용량만큼 요금이 청구됩니다.
- **키가 없어도 앱의 모든 기능은 규칙 기반으로 완전히 동작합니다.**

## 파일 구조

```
index.html
manifest.json          PWA 매니페스트 (이름·아이콘·standalone 표시)
sw.js                  서비스 워커 — network-first, 오프라인 폴백
icon-192.png / icon-512.png / icon-maskable-512.png
apple-touch-icon.png / favicon-64.png / icon.svg
assets/
  css/style.css
  js/
    mbti-data.js   16유형 원자료 + 인지기능 → 역량 점수 계산 + 한국어 조사 처리
    roles.js       과제용 역할 12종 + 요구 역량
    scenes.js      상황 11종 판별 + 상황별 포지션·답변 템플릿 + 양자택일 선택지 추출
    analyzer.js    질문 분석 (상황 / 주제 / 답변 축 / 키워드 / 우선순위)
    engine.js      포지션 배정 알고리즘 + 케미 진단
    answers.js     MBTI별 예상 정답 생성
    llm.js         (선택) Claude API 호출
    app.js         UI + 서비스 워커 등록
```

> 코드를 고친 뒤 캐시를 확실히 갈아엎으려면 `sw.js` 상단의 `CACHE` 값을 올리세요 (`bymbti-v1` → `bymbti-v2`).
> 평소에는 network-first라 새로고침만 해도 최신이 반영됩니다.
